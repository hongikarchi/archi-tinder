## 시작하기

```bash
cd frontend && npm run dev -- --port 5173 --strictPort
```

**포트 5173 필수.** 백엔드 CORS가 `5173,5174`만 허용하고, 다른 세션이 5174를 잡고 있으면 Vite가 조용히 5175로 밀려서 dev 로그인이 "Failed to fetch"로 죽음.

`/login` → **Dev login** 클릭하면 인증됨.

### 시안 나란히 보기

```
http://localhost:5173/__mocks/_compare.html
```

왼쪽 시안 / 오른쪽 실제 앱. 보드 고르면 대응 라우트로 자동 이동. 상단에서 `overlay` 모드 선택하면 두 화면이 겹치고 슬라이더로 투명도 조절 가능 — 픽셀 차이 볼 때 씀.

개별 시안은 `http://localhost:5173/__mocks/<보드이름>.html`.

> `frontend/public/__mocks/`는 gitignore돼 있음. 확인 끝나면 지워도 됨.

## 확인할 것 — 우선순위 순

### 1. 전 페이지 공통 (가장 눈에 띔)

| 항목 | 기대 |
|---|---|
| **Archibe 로고** | 모든 페이지 상단 중앙, `Arch`(본문색) + `ibe`(강조색). 17개 페이지 적용 |
| **TabBar 활성색** | 파랑(`--accent-1`). 기존엔 4개 테마 전부 핑크 고정이었음 |
| **CTA 버튼** | 전부 단색. 그라데이션 없음 |

### 2. 라이트 테마에서 "안 보이던" 것들

`rgba(255,255,255,0.0X)`를 배경으로 쓰면 흰 배경 위 흰색이 됨. 다크 테마 전제로 짜인 값들이라 라이트 테마에서 요소가 사라져 있었음. 20곳 이상 고침.

**확인**: github-light / ayu-light에서 —
- 프로필 보드/프로젝트 카드가 이미지 로드 전에 보이는지
- 저장 모달, 서프라이즈 모달의 행 배경이 보이는지
- 검색 결과 스트립이 보이는지

### 3. 테마 따라 안 바뀌던 색

- Discovery 비활성 버튼이 GitHub Light 파랑으로 고정이었음 (4테마 전부)
- 프로필 편집 오류 배너가 GitHub Light 빨강으로 고정이었음
- Tailwind 기본 팔레트 잔재(핑크·빨강·로즈·인디고) 40곳 이상 → 토큰

**확인**: 테마를 4개 다 돌려보며 색이 같이 바뀌는지.

### 4. 한국어 표시

- 취향 리포트 축 레이블이 **영어 고정**이었음 → 형태/물성/스케일/에너지/전통성
- Discovery 오류·빈 상태 문구 5개가 영어 하드코딩이었음

## 판단이 필요한 것 (NEEDS EYEBALL)

### A. 결정 대기 — 아직 아무것도 안 함

1. **sticky 헤더 → 인플로우 제목.** 시안 전체가 앱의 sticky 반투명 헤더 바(뒤로가기 + 가운데 제목 + blur)를 없애고, 평범한 좌측정렬 `<h2>` + 좌상단 떠 있는 원형 뒤로가기 버튼으로 바꿈. **~40개 파일**에 걸리고 스크롤 동작이 바뀜(제목이 안 따라옴). 메이커 두 명이 독립적으로 지적했고, 로고 결정과는 별개 사안이라 손대지 않았음. → **별도 PR 필요**

2. **`#fbbf24` 저장/북마크 노랑.** 대응 토큰이 없음. `--accent-3`는 라이트 테마에서 `#953800` **갈색**이라 "저장됨" 표시가 갈색이 됨. 의미가 깨져서 그대로 뒀음. 업로드 커버 뱃지 `#ffd700`도 같은 문제. → 상태 표현용 토큰(성공/경고) 정의가 필요함

3. **모달 배경 어둡기.** `DESIGN.md` §1.4는 표준 배경을 0.65라 하고 §8.10은 0.4라 하는데, 실제 코드와 시안은 둘 다 0.4를 씀. 0.4 대응 토큰이 없음. 0.4 배경은 건드리지 않았음.

### B. 시안과 일부러 다르게 간 것

- **`font-weight: 800`** — 시안 여러 곳이 800인데 `DESIGN.md` §2.5가 700 상한이라 700으로. 시안이 기존 위반을 그대로 복사한 것으로 판단
- **흰색 워시** — 시안도 `rgba(255,255,255,0.04)`를 갖고 있지만 그건 기존 버그를 복사한 것. 라이트 테마 가독성 우선
- **첫 로그인 카드** — 시안은 카드 안 헤더(워드마크·언어토글·제목)를 통째로 없앰. 언어 스위처가 카드 밖으로 이동하는 구조 변경이라 별도 판단 필요
- **구글 G 마크** — 시안은 단색화. 브랜드 가이드라인 문제라 그대로 둠
- **보드 그리드** — 시안은 4열 고정, 코드는 반응형 유지
- **SwipePage 프로젝트명** — 시안이 그 자리를 로고로 대체함. 이름이 안 보이게 됨

### C. 대비가 애매한 곳

**ayu-light** 테마에서 강조색 위 작은 글자가 WCAG AA 미달(약 2.3~2.5:1). 이번에 생긴 게 아니라 원래 있던 특성이고, 태그 칩 등에 그대로 남아 있음. 고치려면 ayu-light 강조색을 어둡게 하거나 칩 글자에 별도 토큰을 줘야 함 — 테마 전체에 영향.
