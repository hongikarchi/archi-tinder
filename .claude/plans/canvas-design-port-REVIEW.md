## 이번에 바뀐 것 — 확인 순서

### 1. 전 페이지 공통 (가장 눈에 띔)

| 항목 | 확인 |
|---|---|
| **우상단 컨트롤** | 언어(한국어/ENGLISH) + 테마(해/달) + 로그아웃 원형. 42개 보드에 있던 걸 앱엔 없던 것 |
| **헤더 구조** | sticky 반투명 바 제거 → 좌상단 떠 있는 원형 뒤로가기 + 제목이 본문에 좌측정렬. **제목이 스크롤에 따라 올라감**(승인된 변경) |
| **Archibe 로고** | 모든 페이지 상단 중앙 |
| **TabBar 활성색** | 파랑. 기존엔 4테마 전부 핑크 고정이었음 |

### 2. 라이트 테마에서 안 보이던 것

`rgba(255,255,255,0.0X)` 배경은 흰 배경 위 흰색이 됨. 다크 전제로 짜인 값이라 라이트에서 요소가 사라져 있었음. 20곳 이상 수정.

**확인**: github-light / ayu-light에서 프로필 보드 카드, 저장 모달 행, 검색 결과 스트립이 보이는지.

### 3. 테마 따라 안 바뀌던 색

Discovery 비활성 버튼, 프로필 오류 배너가 GitHub Light 색으로 고정이었음. Tailwind 잔재(핑크·빨강·로즈·인디고·앰버) 40곳 이상 → 토큰.

**확인**: 4테마 돌려보며 색이 같이 바뀌는지.

### 4. 한국어 표시

취향 리포트 축 레이블이 **영어 고정**이었음 → 형태/물성/스케일/에너지/전통성. Discovery 오류·빈 상태 문구 5개도.

### 5. 로그인 화면 (구조가 바뀜)

로고와 언어 토글이 카드 밖 페이지 레벨로 이동. 첫 카드의 제목·워드마크·타이핑 문구 제거. credentials 등 나머지 카드는 카드 안 워드마크·타이핑 문구 제거, 패딩 `40px 36px`, 세로 중앙.

## 눈으로 판단해야 할 것

### A. 되돌릴 수 있는 카피 삭제

로그인 첫 화면 본문에서 `10~15장이면 취향 프로필이 완성돼요`가 빠졌음. 시안이 한 줄이라 그대로 반영했는데, 이 문장은 CLAUDE.md에 적힌 **핵심 약속**을 첫 화면에서 말하는 것임. 한 줄 되돌리면 됨.

### B. 결정이 필요한 것

1. **`#fbbf24` 저장/북마크 노랑** — 대응 토큰 없음. `--accent-3`는 라이트 테마에서 `#953800` **갈색**이라 "저장됨" 의미가 깨짐. 상태 표현용 토큰(성공/경고) 정의 필요.
2. **모달 배경 어둡기** — `DESIGN.md` §1.4는 0.65, §8.10은 0.4로 서로 다르게 말하는데 실제 코드와 시안은 둘 다 0.4. 0.4 대응 토큰이 없어서 안 건드림.
3. **`UserProfilePage` 뒤로가기** — 시안엔 떠 있는 버튼이 있는데 앱엔 뒤로가기 코드가 아예 없음. `/user/me`는 TabBar 루트라 "어디로 돌아갈지"를 정해야 함.
4. **appearance 폰트 칩 모양** — 시안 `border-radius:10px`(둥근 사각), 앱 `--radius-pill`(완전 pill). 10px에 해당하는 토큰이 없고 공용 `.chip` 클래스라 모양을 바꾸면 파급이 있음.

### C. 시안과 일부러 다르게 간 것

- **`font-weight: 800`** — 시안 여러 곳이 800인데 `DESIGN.md` §2.5가 700 상한. 시안이 기존 위반을 복사한 것으로 판단
- **흰색 워시** — 시안도 갖고 있지만 기존 버그 복사. 라이트 테마 가독성 우선
- **업로드 제출 버튼 패딩** — 시안 `12px`가 §8.1의 `14-16px` 하한 위반. 앱이 더 맞음
- **구글 G 마크** — 시안은 단색화. 브랜드 가이드라인 문제
- **보드 그리드** — 시안 4열 고정, 코드는 반응형 유지
- **`ArchitectProfilePage` 공유 버튼** — 시안에 없지만 동작하는 기능이라 유지, 뒤로가기 아래(`top:58`)에 임의 배치

### D. 대비

**ayu-light**에서 강조색 위 작은 글자가 WCAG AA 미달(약 2.3~2.5:1). 원래 있던 특성이고 태그 칩 등에 남아 있음. 고치려면 ayu-light 강조색을 어둡게 하거나 칩 글자에 별도 토큰 — 테마 전체 영향.
